# 聊天图片的复制与保存

聊天里已经在本机的图片（气泡里直接显示的那种）可以复制到系统剪贴板，或另存到用户选的位置。

- 入口：在图片气泡上点右键，菜单有「复制图片」「另存为…」；点开大图后，图片下方有同样的两个按钮。
- 复制：往系统剪贴板放一张 PNG。原图是 PNG 时原样放入，其它格式（JPEG、GIF、WebP、BMP）
  先解码再编码成 PNG（动图只取第一帧）。成功提示「已复制图片」；文件读不了、解码失败或平台没有
  剪贴板时提示「复制图片失败。」。
- 另存为：弹系统保存对话框，默认文件名是消息里的文件名（收到的用 `safeName`）；用户取消则
  什么都不做。目标已存在时先问是否覆盖。把本机那份文件原样拷过去，成功提示「已保存图片」，
  失败提示「保存图片失败。」。
- 两个操作都只读本机已有的文件，不触发网络请求，不改消息状态。

实现：`lib/ui/chat_images.dart`（PNG 转换、写剪贴板、菜单和大图界面），
`lib/ui/chat_screen.dart`（保存位置、覆盖确认和提示）。
