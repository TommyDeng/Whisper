# 界面改版：霓虹终端（方向 D）

> 状态：所有者已确认（2026-11-14），已按本文件实现。

效果图：<https://www.figma.com/design/toPrYFn6DiCIVKGWG6taLs>
左侧看板"主界面 · 四个方向"里标了"已选"的方向 D 是主界面，右侧看板"方向 D · 其余页面与控件"是其余页面和控件表。**颜色、间距、文案以本文件为准，观感以效果图为准。**

## 为什么改

现在的界面是"极简线条风"：黑白单色、细线、手机式的整页跳转。所有者的评价是"简约朴素，没有被设计过的美感"。在四个方向里选定了赛博朋克 / 黑客风的方向 D。

## 目标

1. 整个应用换成一套深色的霓虹终端风格，所有页面和对话框观感一致。
2. 宽窗口用左右分栏：左边联系人，右边聊天，同屏可见。
3. 颜色各管一件事：绿＝正常和可点，黄＝需要留意，红＝警告和危险。

## 不做

- 不加新功能：消息时间、最后一条消息预览、搜索框都不加。
- 不做浅色 / 深色切换，全应用只有这一套。
- 不改任何业务逻辑、协议、存储、`worker/`。
- 不改现有文案，除了下面"新增文案"列出的几处。

## 不能出现的结果

- 为了风格牺牲可读性：聊天正文、按钮文字、错误说明必须清晰好读。
- 装饰文字说了不真实的话（例如在走中继时显示"P2P"）。
- 头像按人分色。头像只表示在线 / 离线。

## 形状和字体

- 圆角全部 2px（气泡、按钮、输入框、头像、对话框、角标）。验证徽章保持圆形。
- 中英文正文：Inter，回退到现有的中文系统字体列表。等宽：JetBrains Mono，用于指纹、邀请码、安全码、通话时长、文件大小和进度、下载地址、装饰标签。
- 两种字体随应用打包到 `assets/fonts/`（各带 OFL 许可证文件）。Inter 用 400 / 500 / 600 / 700，JetBrains Mono 用 400 / 500 / 600。**不打包中文字体。**
- 字号沿用效果图：边栏标题 22/700，联系人名 15/500（有未读 600），聊天标题 16/600，消息 14.5 行高 21，副标题和说明 12，按钮 13.5/600，装饰标签 10–11 字距 1。

## 布局

窗口宽度 ≥ 720 时分栏，< 720 时单栏。

**分栏**
- 左栏固定宽 300，右栏占满剩余宽度。通话条仍在窗口最顶部，横跨两栏。
- 点联系人：右栏显示这个人的聊天，不跳页；这一行变成选中样式（主色暗底 + 左侧 2px 主色竖条）。
- 没选联系人：右栏显示空状态"选一个联系人开始聊天"。
- 换联系人：右栏换成新的聊天，输入框里没发出去的字不带过去。
- 删除正在看的联系人：右栏回到空状态。
- 旧版联系人（没有会话）：和现在一样弹提示，不选中。
- 未读数：打开某人的聊天后清零，规则和现在一样。

**单栏**
- 和现在一样：先看到联系人列表，点进去是整页聊天，有返回按钮。
- 分栏时已选中某人，窗口拖窄到 < 720：显示这个人的聊天，返回后回到列表。再拖宽：回到分栏，保持选中。

## 各部分

**边栏**
- 顶部高 64：左边"耳语"加装饰标签 `WHISPER_`；右边三个图标按钮：添加联系人、关于、更多（菜单里是"清除全部数据…"，红字）。
- 有配对请求时，下面一条主色暗底横幅"有 N 个配对请求等你处理"，点了打开配对。
- 联系人行高 60：方形头像 40、名字 + 验证徽章、第二行"在线 / 离线" + 等宽的指纹（公钥前 4 个字节的十六进制，带 `0x`；原来显示的是 Base64 前 8 位，配 `0x` 名不副实）、右边未读数（红底）。悬停出现删除按钮，和现在一样。
- 底部一行弱文字：盾牌图标 + `E2EE · X25519`。

**头像**
- 方形，1px 描边，里面是名字的第一个字。
- 在线：主色描边、主色字、主色暗底，右下角一个带辉光的主色小方点。
- 离线：弱文字色描边和字、收到的气泡色做底，没有小方点。

**聊天**
- 标题栏高 64：头像 36、名字 + 验证徽章、副标题沿用现在的"已验证 / 未验证 · 连接状态"原文。右边：通话按钮（主色暗底 + 主色边）、阅后即焚按钮（开启时用警告红）。点名字区域仍然打开安全码。
- 收到的气泡：收到的气泡色底 + 描边。自己发的：自己发的气泡色 + 主色 1px 边 + 辉光。气泡最大宽度规则不变。
- 自己发的气泡左边：发送状态图标（弱文字色；失败用警告红），阅后即焚的火焰用警告红。
- 收到的每条消息左边原来有一个验证徽章，改版后去掉：安全状态只在边栏和聊天标题栏常驻显示。
- 输入区：左边回形针；输入框高 40，开头一个主色等宽 `>`，里面右侧是方形主色发送按钮。阅后即焚开启时回形针变灰不可点，和现在一样。

**图片消息**：行为不变（缩略图、点开看大图、复制、另存）。缩略图圆角 2px，自己发的带主色 1px 边；大图查看的遮罩用聊天底色加透明度。

**通话条**（高 56，面板底，左侧 3px 色带）
- 来电：色带和状态文字用警告红；"拒接"红边，"接听"主色底。
- 通话中：色带主色；等宽时长；锁图标 + "端到端加密 · 线路"；麦克风电平条用主色；"静音"普通按钮，"挂断"红底。
- 重连中：色带和状态文字用留意黄。已静音时按钮是主色暗底的"取消静音"。
- 已结束及各种失败结果：色带用描边色，只有"关闭"。

**文件**
- 文件卡：输入底 + 描边，左边 36 方形图标块，名字，等宽的大小 / 进度 / 线路说明，右边按钮。
- 进度：3px 细线，已完成段主色带辉光。
- 失败：警告红暗边、红色图标和说明。
- 按钮主次：接受 / 下载用主按钮；打开所在位置 / 重试用次按钮；取消 / 关闭用普通按钮；拒绝用红边按钮。

**对话框**
- 面板底 + 描边，标题栏高 48，标题旁一个等宽装饰标签，右上角关闭。
- 标签：添加联系人 `PAIR_`，配对请求和安全码 `VERIFY_`，关于 `ABOUT_`，普通确认 `CONFIRM_`，不可恢复的操作 `DANGER_`。
- 普通确认的确认键是主按钮；不可恢复的操作（清除全部数据、删除联系人）的确认键是红底按钮。

**配对对话框**
- 我的名字：输入框。我的邀请码：主色暗底 + 主色边的块，等宽大字，右边"复制"，下面是现有的有效期说明。
- 输入对方邀请码：输入框内右侧"粘贴邀请码"，下面右对齐"配对"主按钮。
- 对方请求：头像 + "某某 请求添加你"，安全码用等宽大字、留意黄，"拒绝"红边、"批准"主按钮。
- 等待中：一条输入底的状态条，左边转圈，右边"取消"。

**关于对话框**：版本号等宽主色；有新版本时黄字提示 + "更新"主按钮；开机自动启动用方形开关；下载地址等宽显示，右边复制图标。

**小控件**
- 按钮高 36：主（主色底）、次（主色边）、普通（描边色边、次要文字）、危险（红边）、危险确认（红底）、不可用（暗底弱文字）。
- 开关：38×20 方形，开＝主色边 + 主色方块靠右，关＝描边色边 + 弱文字色方块靠左。
- 菜单：面板底 + 描边，悬停项主色暗底，危险项红字。
- 提示条：主色暗底 + 主色边 + 辉光。悬停提示：收到的气泡色底 + 描边。
- 滚动条：细，描边色。

## 第二轮：动效、链接和视频、图标（2026-11-14）

所有者看过第一版后提的五点，取代上面"建议不加新动画"那句。

**按钮**：全应用只有两套实现，手感一样：悬停变亮（描边按钮铺一层淡底，实心按钮提亮），按下整体缩到 0.94，松开弹回；快速点击也至少保持按下 90ms。
- Material 按钮（Filled / Outlined / Text）：`AppTheme` 的 ButtonStyle 用 `backgroundBuilder` 调 `ButtonSkin`，底色和描边都在 `ButtonSkin` 里画。
- 图标按钮：`TermIconButton`（无底）和 `SquareIconButton`（有底），底下都是 `Pressable`。`lib/` 里不再用 `IconButton` 和 `PopupMenuButton`。
- 时长和曲线都在 `lib/ui/motion.dart` 的 `Motion` 里。

**添加联系人卡顿**：原因是对话框先显示转圈，邀请码生成后二维码塞进来，对话框在弹出动画中途变高、重新居中；配对状态每变一次二维码都整块重画。改为：生成前后占位大小一样（测试断言对话框尺寸不变），已有邀请码时第一帧就显示，二维码只在邀请码变化时重建。

**弹出动效**：所有对话框改用 `showTermDialog`（淡入 + 从 0.95 放大 + 上移一点，200ms）；分栏右侧换人、单栏进出聊天用 `PaneSwitcher` 淡入并右滑一点。

**聊天内容**
- 文字里的 `http://`、`https://`、`www.` 链接高亮带下划线，鼠标变手形，点了用系统浏览器打开；只放行 http / https。
- 右键文字：复制、全选；右键在链接上时多出"打开链接""复制链接"。没选中文字时"复制"复制整条。
- 图片：仍然内联显示，点开大图（滚轮缩放、拖动、Esc 关闭），右键复制 / 另存。
- 视频（mp4、mov、webm、mkv 等）：下载到本机后画成 16:9 的视频卡片，点了用系统播放器打开，右键可以播放或打开所在位置。**不做内嵌播放**：桌面端内嵌播放要引入 libmpv 一类的原生依赖，所有者如需要再单独做。

**图标**：近黑方块底 + 荧光绿方形对话气泡，气泡里是 `>_`；有未读时右上角多一个警告红方块。32px 及以下用去掉辉光的加粗版，托盘里看得清。由 `tool/generate_app_icons.py` 生成，改图标改这个脚本再跑一遍。
