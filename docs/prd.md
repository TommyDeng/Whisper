# 耳语（Whisper）产品需求文档（PRD）· Stage 1

> 状态：草案 · 形态：原生客户端（Flutter），首发 Windows / Linux 桌面，后续 iOS / Android · 中继：`whisper.tommydeng.org`（Cloudflare，仅转发密文）

## 1. 产品定位
耳语是一个**只给亲友使用**的私密通讯工具：端到端加密（E2EE）的文字聊天 + 低延迟实时语音。**安全优先于一切功能**。没有陌生人、没有随机匹配、没有多余社交功能，尽量少收集数据，不需要手机号或邮箱注册。

## 2. 目标用户与场景
- **用户**：项目所有者本人及其家人、密友（预计 < 20 人）。
- **场景**：
  1. 和家人发日常私密消息（地址、证件信息、家庭事务）。
  2. 和朋友进行一对一实时语音通话，不想经过大平台。
  3. 见面时扫码互加；不在身边时通过私下分享的一次性邀请链接互加。

## 3. MVP 范围（Stage 2）
| 功能 | 说明 |
|---|---|
| 本地身份 | 首次启动在本机生成身份密钥对，私钥存于系统安全存储，无账号、无手机号/邮箱 |
| 配对 | 当面：一方显示二维码，另一方用摄像头扫描；无摄像头时粘贴邀请码。远程：私下分享邀请码/链接（含公钥 + token）。邀请码**一次性、24 小时有效**，被使用后**须邀请人手动批准**才建立联系 |
| 安全码验证 | 双方比对安全码（Safety Number），防中间人攻击（MITM）；未验证时 UI 明确提示 |
| 1:1 E2EE 文字聊天 | 在线实时转发；离线时服务器只暂存密文，送达即删 |
| 1:1 E2EE 语音通话 | WebRTC 点对点，DTLS-SRTP 加密；连接优先级：局域网 → ZeroTier 虚拟局域网 → 公网 P2P（STUN）→ Cloudflare TURN 中继 |
| 身份 | **一台设备 = 一个身份**；MVP 无多设备同步、无备份 |
| 会话类型 | **仅 1:1**，群聊后续 |
| E2EE 图片与文件 | **对方在线且存在直连（局域网 / ZeroTier / 公网 P2P，不含 TURN）：单文件 ≤ 100GB**，流式分块加密直传，支持断点续传、进度/暂停/取消；**否则（对方离线或无直连，仅能经 R2 中转）：单文件 ≤ 100MB**，分块加密后暂存 Cloudflare R2，下载后或 7 天删除。**传输路径优先级：局域网（物理局域网 / ZeroTier）→ 公网 P2P 直连 → R2 中转（最后手段）；文件永不经 TURN 传输** |
| 本地历史 | 只存本机，加密存储（密钥在系统安全存储）；**默认保留 7 天后自动删除**；每个会话可手动开启“阅后即焚”；可一键清除 |
| 安装包 | Windows：exe 安装器 + 便携 zip（未签名，不购买证书）；Linux：AppImage / deb；均附 SHA-256 + GPG 签名校验和 |

**后续（非 MVP）**：小型家庭群聊（≤ 10 人）、多设备同步、加密备份、双棘轮（Double Ratchet）前向保密、可自定义历史保留时长。

### 连接策略：局域网优先
1. 同一物理局域网直连（可选 mDNS 发现）；
2. ZeroTier 虚拟局域网（所有者和朋友已在使用）；
3. 公网 P2P（STUN 打洞）；
4. Cloudflare TURN 中继兜底（在免费额度内，MVP 默认启用）。

ZeroTier 只是**传输加速手段，绝不是安全边界**：无论走哪条路径，E2EE 始终开启。没有 ZeroTier 也必须能正常使用（家人、未来移动端）。

## 4. 明确的非目标
- 不做陌生人搜索、附近的人、随机匹配、公开资料页。
- 不做朋友圈/动态、表情商店、已读回执排行等社交功能。
- 不做手机号/邮箱注册、通讯录上传。
- 不做广告、数据分析埋点、第三方 SDK 追踪。
- 不做 Web 版 / 浏览器客户端。
- MVP 不做视频通话、超过上限的文件（直连 100GB / 中转 100MB）、群聊、多设备同步/备份、移动端（iOS/Android 在后续阶段用同一代码库发布）。

## 5. 隐私原则
1. **服务器只见密文**：所有内容在客户端加密，服务器无解密能力。
2. **不存明文**：服务端任何地方（日志、存储）都不出现明文。
3. **短暂/有限留存**：服务器离线密文（消息与 R2 文件块）送达/下载后立即删除，未送达的**最长 7 天**自动清除；本机历史默认 7 天自动删除，可按会话开启阅后即焚。
4. **最少元数据**：不记录 IP 日志（关闭不必要的 Worker 日志），会话 ID 使用随机不可关联标识。
5. **用户掌控**：密钥只在本地，用户可随时清除全部数据。

## 6. 威胁模型摘要
| 威胁 | 应对 |
|---|---|
| 服务器/Cloudflare 被攻破或被查看 | E2EE，服务器只有密文 |
| 中间人在配对时替换公钥 | 当面扫码 + 安全码比对 |
| 邀请码泄露 | 一次性、24h 有效、使用后失效；**邀请人须手动批准**，陌生人拿到邀请码也无法直接加上 |
| 文件在云端被读取 | 每个文件随机密钥加密，密钥只在 E2EE 消息中传递；R2 只存密文分块，下载后或 7 天删除 |
| 网络窃听 | TLS + E2EE；语音 DTLS-SRTP |
| 元数据（谁和谁、何时通信） | 部分可见于服务器，见架构文档“风险” |
| 设备丢失/被盗 | 依赖设备锁屏；后续可加本地口令加密 |
| 安装包或依赖被篡改（供应链） | 依赖最少、锁版本（pubspec.lock）、CI 公开构建、GitHub Releases 发布 SHA-256 校验和 + GPG 签名的校验和文件（Windows 不购买代码签名证书） |

**不在防护范围内**：已被控制的终端设备、对方截屏/转述。

## 7. Stage 2 MVP 验收标准
- [ ] Windows 与 Linux 安装包可安装运行；无需任何注册即可生成身份；重启应用后身份仍在，私钥位于系统安全存储。
- [ ] 两台设备可通过摄像头扫码或粘贴邀请码完成配对；邀请码二次使用失败、超过 24h 失效；邀请人未批准前不能建立联系、不能收发消息。
- [ ] 双方显示相同安全码；可标记“已验证”，密钥变化时显著告警。
- [ ] 文字消息端到端加密；抓包/查看 Durable Object 存储只能看到密文。
- [ ] 对方离线时消息被暂存，上线后送达，送达后服务端删除；未送达满 7 天自动删除。
- [ ] 本机历史超过 7 天自动删除；开启阅后即焚的会话中，消息被阅读后双方本机删除。
- [ ] 中转文件（≤ 100MB）：对方离线或仅 TURN 可用时经 R2 中转，R2 中只有密文分块，下载后删除、7 天未下载自动删除；超过 100MB 被拒绝并提示（可建议对方上线后直连发送）。
- [ ] 直连大文件：对方在线且直连（局域网、ZeroTier、公网 P2P 各测一次）时可发送 > 100MB 文件，实测至少一个 ≥ 10GB 文件；仅 TURN 可用时文件不走 TURN，自动改走 R2 并按 100MB 上限处理；局域网/ZeroTier 与公网直连同时可用时优先局域网；> 100GB 被拒绝。
- [ ] 大文件传输内存占用稳定（不随文件大小增长）；中途断网/重启后可断点续传；接收端整文件哈希校验通过，篡改任一分块会被检测并重传；支持进度、暂停、取消；接收方磁盘空间不足时传输前即提示。
- [ ] 1:1 语音（Windows↔Linux）可接通，同一网络/常见家庭 NAT 下端到端延迟 < 300ms。
- [ ] 语音实测三种路径均可接通并显示当前路径：①同一局域网；②ZeroTier（双方不在同一物理网络）；③强制仅 TURN 中继。
- [ ] 同时具备局域网/ZeroTier 与公网候选时，优先选中局域网/ZeroTier 路径。
- [ ] 关闭 ZeroTier 后仍可通过 STUN/TURN 正常通话与聊天。
- [ ] 所有路径下媒体与消息均为 E2EE（抓包验证）。
- [ ] 中继部署于 `whisper.tommydeng.org`（WSS），仅可见密文。
- [ ] GitHub Actions 自动构建 Windows / Linux 产物；Release 附 `SHA256SUMS` 与 GPG 签名 `SHA256SUMS.asc`，可按文档验证。
- [ ] 未签名的 Windows 安装包可按文档（SmartScreen“更多信息 → 仍要运行”）完成安装。
- [ ] 所有改动经 PR 并由所有者批准合并。

## 8. Stage 3：极简“线条风”UI 说明
- 黑白/单色细线条风格，留白多，无头像墙、无红点轰炸。
- 主要界面仅三屏：联系人列表、聊天、通话。
- 安全状态（已验证/未验证）用简单线条图标常驻显示。
- 桌面端优先（窗口可缩小为窄栏），布局为后续移动端预留；Flutter 同一套组件。
