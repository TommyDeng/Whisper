# 耳语（Whisper）已确认决策

> 状态：已由所有者确认（截至 2026-11-02）· 本文件记录阶段一验收后、阶段二进行中的产品与工程决策，供后续开发与验收对照。

## 产品与范围

| 决策 | 内容 |
|---|---|
| 受众 | 仅亲友，不做陌生人社交；安全优先于功能 |
| 形态 | 原生客户端（Flutter），首发 Windows + Linux；iOS / Android 后续；不做 Web 客户端 |
| 中继 | Cloudflare 仅作密文中继与信令；域名 `whisper.tommydeng.org` |
| MVP 会话 | 仅 1:1；群聊延后 |
| MVP 身份 | 一台设备 = 一个身份；多设备延后 |
| 邀请码 | 一次性、24 小时有效；对方使用后须邀请人手动批准 |
| 本地历史 | 默认保留 7 天；每个会话可手动开启阅后即焚 |
| 离线密文 | 服务端最长存 7 天 |
| 文件上限 | 对方在线且有直连（物理局域网 / ZeroTier / 公网 P2P）时单文件 ≤ 100GB；否则（中继 / R2）≤ 100MB |

## 连接与安全

| 决策 | 内容 |
|---|---|
| 连接优先级 | 物理局域网 → ZeroTier 虚拟局域网 → STUN P2P → Cloudflare TURN（免费额度） |
| ZeroTier | 仅传输加速，**不是**安全边界；无论路径如何，E2EE 始终开启 |
| 密码学 | X25519、Ed25519、XChaCha20-Poly1305 |
